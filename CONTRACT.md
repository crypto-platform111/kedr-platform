# KEDR initial application contract (schema 1 compatibility reference)

This document records the original 0.1 contracts retained for compatibility. Current 0.2 extensions are described in README.md, ARCHITECTURE.md and the versioned application modules. A clone can run from any writable project directory using the documented synthetic demo data; historical archives are an optional separately installed input.

Local only; Russian default + English; backend FastAPI/SQLite, frontend Vite React TypeScript. No old runner imports, no accounts, no market downloads, no2026observation values. Root orchestrator owns environment/dependencies/docs/tests integration; assigned owners edit disjoint files.

backend/app/data.py: datasets()->list[metadata]; load_dataset(dataset_id)->dict with metadata and bars. Metadata{id,name,symbol,timeframe,start,end,bars,source_type,sha256,description,gaps,verified}; source_type verified_historical or synthetic_demo.
backend/app/engine.py: run_backtest(spec,dataset,config)->dict; explain_result(result,locale='ru')->structured deterministic offline report. Pure standard library where practical.

Spec{schema_version:1,symbol:'BTCUSDT',timeframe:'4h',nodes:[{id,type,params,position:{x,y}}],edges:[{id,source,target,sourceHandle?:'out',targetHandle?:'input'|'a'|'b'}],risk:{max_exposure:1,stop_loss_pct:null,take_profit_pct:null}}. Supported: price,volume,constant,sma,ema,rsi,macd,bollinger,volatility,returns,gt,lt,cross_above,cross_below,and,or,enter_long,exit_long,hold_cash,position_size,stop_loss,take_profit,max_exposure,market. Future unavailable types news_sentiment,ml_prediction,funding,external_api. Indicators use targetHandle input; comparators/logic a/b; actions input. No arbitrary code. graph acyclic, ports/type compatibility validated. Root spec risk remains canonical default; risk-node precedence must be documented deterministically.

Config{start:'2022-01-01',end:'2025-12-31',initial_cash:10000,fee_bps:10,slippage_bps:2,execution_delay_bars:1}. Interpret delay1 as signal at completed bar_i then execute open_i+2, allowing a full candle for publication/decision; no signal-close execution. Bar timestamps ISO UTC. Inputs temporal gaps cause warmup reset and no cross-gap order fills, report exclusions/valuation limitations. Terminal open positions remain marked and disclosed, no invented fills.

## API-owned modules
backend/app/main.py,db.py,auth.py,providers.py; backend/migrations; backend/tests/test_api.py. Import engine modules above. Register/init app on startup; no imports of old trading code. DB runtime data platform.sqlite3 under the configured platform data directory. Session cookies HttpOnly SameSite strict, CSRF token for mutations, ownership enforced per server route, password scrypt hash; isolated demo-session user no shared credentials. Demo auth remains local-only; host loopback default.

All /api endpoints JSON. Error {detail:string|validation}. Frontend sends credentials same-origin, X-CSRF-Token from auth response for mutations. Safe read /api/health.
GET/auth/me -> {user:{id,email,name,level,locale,timezone,theme,is_demo},csrf_token};401none.
POST/auth/demo {} -> same auth response; POST/auth/register {email,password,name}, /login {email,password}; POST/logout; PATCH/profile {name?,level?,locale?,timezone?,theme?}.
GET/templates -> list; GET/nodes -> catalog; GET/datasets -> list; GET/providers -> list truth statuses.
GET/strategies -> list; POST/strategies {name,description?,tags?,spec} -> strategy. GET/strategies/{id}; PUT same updates editable saved current draft; POST/{id}/versions -> immutable snapshot; POST/{id}/duplicate; DELETE private own.
Strategy{id,owner_id,name,description,tags,spec,latest_version_id,version_number,created_at,updated_at}. Version{id,strategy_id,number,spec,spec_hash,created_at}. GET/{id}/versions -> list.
POST/validate {spec}->validation dict.
POST/backtests {strategy_id,version_id?,dataset_id,config} -> job{id,status,run_id?}; bounded worker abstraction executes immutable version. GET/jobs/{id} poll; GET/backtests -> user's run summaries; GET/backtests/{run_id} -> engine result plus id,strategy_id,version_id,dataset,config,status,created_at.
GET/backtests/{run_id}/analysis?locale=ru -> {mode:'offline_rules',provider_status,summary,sections:[{title,body}],...}; no external AI implied.
POST/community {strategy_id,version_id,run_id,description?,tags?}->immutable publication only if owned actual run matches exactversion. GET/community -> public listings {id,name,author,description,tags,symbol,version_id,run_id,metrics,dataset,created_at,verification:'reproducible_snapshot'}; GET/community/{id}; POST/community/{id}/fork -> private strategy with fork link. Never expose unpublished spec/runs to other users. No unrequested outbound messages.
GET/news?symbol=BTCUSDT -> {mode:'demo_fixture',articles:[{id,title,summary,sentiment,published_at,first_seen_at,url?,symbol}],provider_status}; fixtures clearly labelled not current.
GET/ml -> {status:'not_configured',capabilities,...}; POST/ml/drafts save research configuration only no training. GET/bots -> {status:'preview_only',bots:[],...}; no live start/stop pretend.
GET/audit -> own recent audit events; GET/dashboard optional aggregate user's state. AI/news/sentiment/ML provider interfaces with env-only secret configuration and honest disconnected status. Constrained validated natural-language strategy generation interface unavailable without provider, never arbitrary code.
